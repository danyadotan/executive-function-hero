# Git Quest: Branch Hero

**Learn Git through adventure!** An AI-powered narrative game that teaches Git concepts through storytelling.

## GitKon 2025 Game Jam Entry

Guided by **Keif the Kraken**, explore the Commit Realm and master Git through epic quests!

### Features

- **AI-Generated Adventures**: Every playthrough is unique, powered by Google Gemini
- **Git Concepts as Gameplay**:
  - Merge conflicts = Diplomatic negotiations
  - Branches = Parallel timelines
  - Rebasing = Time travel
  - Commits = Save crystals
- **Visual Commit Graph**: Watch your progress grow as you play
- **Accessibility**: Dyslexia-friendly font option
- **GitKraken Themed**: Purple & green aesthetic with Keif as your guide

### How to Play

1. Start your adventure with `git init`
2. Make choices to progress through the story
3. Learn Git concepts naturally through the narrative
4. Earn COMMIT POINTS for good Git practices
5. No punishments - mistakes are learning opportunities!

### Run Locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Set your Gemini API key in `.env.local`:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```
3. Run the dev server: `npm run dev`

### Build for itch.io

```bash
npm run build
```

Upload the contents of the `dist` folder to itch.io.
